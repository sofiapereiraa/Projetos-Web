# ✅ Todo List (Gerenciador de Tarefas)

🔗 Acesse o projeto:  
https://sofiapereiraa.github.io/Lista-Javascript/

---

Projeto de lista de tarefas com armazenamento local no navegador.

---

## 🚀 Funcionalidades:
- Adicionar novas tarefas  
- Marcar tarefas como concluídas  
- Editar tarefas existentes  
- Remover tarefas  
- Filtro de tarefas (todas, concluídas e pendentes)  
- Busca de tarefas em tempo real  
- Salvamento automático no LocalStorage  

---

## 🛠 Tecnologias:
- HTML  
- CSS  
- JavaScript  
- LocalStorage (Web API)
