## ✅ Todo List (Gerenciador de Tarefas)

Aplicação de lista de tarefas desenvolvida em JavaScript com armazenamento local utilizando LocalStorage.

### 🌐 Acesse o projeto

👉 https://sofiapereiraa.github.io/Lista-Javascript/

### 🚀 Funcionalidades

- Adicionar tarefas
- Editar tarefas
- Remover tarefas
- Marcar tarefas como concluídas
- Filtrar tarefas (todas, concluídas e pendentes)
- Buscar tarefas em tempo real
- Salvamento automático no LocalStorage

### 🛠 Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage (Web API)
