# Seleção Brasileira Feminina de Vôlei

Site desenvolvido como um projeto de desenvolvimento web dedicado à Seleção Brasileira Feminina de Vôlei.

A ideia surgiu durante um período com várias competições de vôlei acontecendo e também por ser um esporte que gosto muito. O projeto busca reunir, de forma simples e organizada, informações sobre as atletas do ciclo atual da Seleção.

# Projeto

##  Sobre o projeto

O site apresenta informações sobre as atletas, incluindo:

- Nome
- Altura
- História e trajetória
- Informações sobre a Seleção

Além disso, o site possui seções sobre as premiações e sobre a própria Seleção.

##  Funcionalidades

- Menu de navegação
- Página de atletas
- Informações individuais das jogadoras
- Seção de premiações
- Seção sobre a Seleção
- Layout responsivo

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

##  Objetivo

Este é um projeto simples criado para praticar desenvolvimento web e, ao mesmo tempo, desenvolver algo relacionado a um esporte que gosto.

A proposta é continuar aprimorando o projeto aos poucos, adicionando novas informações, melhorias visuais e funcionalidades.
